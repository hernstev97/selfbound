# Logo and brand assets

The original logo (star on the left, "XLR8" lettering on the right, one path with `evenodd`) lives
unchanged in `app/public/brand/xlr8-logo-original.svg`. Everything else is generated from it with
`node tooling/brand.mjs` (needs `rsvg-convert` and ImageMagick). The script never changes the shapes:
it only splits the path into its subpaths and crops with `viewBox`.

| File (`app/public/…`) | Purpose |
| --- | --- |
| `brand/xlr8-mark.svg`, `xlr8-wordmark.svg`, `xlr8-logo.svg` (full logo) | `fill="currentColor"`, takes the surrounding text colour |
| `brand/…-black.svg`, `…-white.svg` | fixed colour for places without CSS (black on light, white on dark backgrounds) |
| `favicon.svg` | star with outline, black or white depending on `prefers-color-scheme` |
| `favicon.ico`, `favicon-16/32/48.png` | fallback: white star on a dark rounded square (readable in light and dark tabs) |
| `apple-touch-icon.png` | 180 × 180, full square (iOS rounds the corners itself) |
| `icon-192.png`, `icon-512.png`, `icon-maskable-512.png` | web manifest (`site.webmanifest`) |
| `brand/og-image.png` | 1200 × 630, social preview image (`og:image`, `twitter:image`) |
| `brand/clerk-logo.png` | 512 × 512, for uploading in the Clerk dashboard |

In the app the logo is an inline SVG (`components/Logo.svelte`, paths in `lib/brand.ts`, generated by
the script): sidebar (mark + wordmark), sign-in screen (full logo) and loading screen (mark).
`app/test/brand.test.ts` makes sure the files and the paths in the app stay in sync.
