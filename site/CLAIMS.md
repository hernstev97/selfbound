# Basis of the comparison on the landing page

The table "How Selfbound differs from most issue trackers" compares Selfbound with the most popular trackers as a
group and names none of them. Every statement about the group has to stay true for them. Checked on
2026-10-13 against the public pricing and product pages of Jira, Asana, ClickUp, Trello, GitHub Issues
and Linear:

| Statement on the page | Basis |
|---|---|
| "Mostly a hosted subscription service" | Linear, Asana ("do not plan to offer an internally hosted version"), ClickUp and Trello ("cloud-only product") are hosted only. Jira and GitHub are mainly cloud; both also sell a self-managed edition (Jira Data Center, GitHub Enterprise Server), hence "mostly". |
| "Proprietary software" | None of the six publishes its application under an open-source licence. Smaller trackers (Plane, OpenProject, Redmine) are open source, hence "most popular" and not "most". |
| "Teams: members and seats" | All six sell plans by user or seat and organise work around workspace or team members. |
| "Paid plans priced per user" | Linear (Basic, Business), Asana (Starter, Advanced), ClickUp (Core, Business), Trello (Standard, Premium), GitHub (Team) and Jira Cloud (Standard, Premium) list per-user prices; Enterprise tiers are quoted. |

Not compared on purpose: sprints and cycles, because they differ per tool (per team, per board, per project).

Recheck the table and the date line below it before the page is listed, and whenever a tracker changes
its model. If a statement no longer holds for most of them, change or remove the row.
