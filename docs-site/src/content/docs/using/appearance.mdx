Selfbound comes with its own colors and a set of well-known editor themes, and it can use any VS Code theme
you like. You find all of it under **Settings → Appearance**. Changes take effect right away, without a
reload.

<Screenshot name="settings-appearance" alt="Settings, Appearance: color scheme and font size for this device, and the theme cards for the dark theme with Selfbound selected" />

Some settings apply only to the device you are on, others to all your devices:

| Setting | Applies to |
|---|---|
| Color scheme, font size | this device |
| Themes, custom themes, theme colors, fonts | all devices |
| Sounds | this device (under Settings → General) |

## Light and dark

**Color scheme** has three choices: **System** follows the setting of your device, **Dark** and
**Light** fix it. To flip between light and dark quickly, run **Toggle light/dark** from the
[command menu](/using/command-menu/). This sets the color scheme to Dark or Light, so it no longer
follows the system until you choose **System** again.

## Themes

You pick two themes: one for dark mode and one for light mode. The color scheme decides which one is in
use. The default is **Selfbound**, the app's own colors.

Each theme card shows swatches of its colors, and the preview below shows how Selfbound looks with it.
Themes come from editors, where some text colors are fainter than an issue tracker can afford. Where a
theme has too little contrast for text, warnings or errors, Selfbound adjusts the lightness of those colors
and says which ones it changed.

### Adjusting colors

For any theme other than Selfbound, **Adjust colors** opens a list of the colors Selfbound uses, grouped into
Surfaces, Lines, Text, Accent, Status and Code. Change any of them; the app updates as you go. Your
changes apply to this theme only, on all devices. The reset button next to a color restores it, **Reset
all** restores the whole theme.

## Your own VS Code theme

<Steps>

1. Under **Custom themes**, click **Add theme**.
2. Paste the theme's JSON into **VS Code theme (JSON)**, or click **Choose file…** to upload it.
   Comments and trailing commas are fine, as in VS Code.
3. Check the preview and the contrast notes, and give the theme a **Name**.
4. Click **Save**, or **Save and use** to switch to it right away.

</Steps>

Selfbound decides from the theme's editor background whether it is dark or light (and falls back to the
theme's `type` if the background is missing). That decides whether it appears as a choice for dark or
light mode.

Where to get the JSON:

- In a theme package, the JSON usually sits in the `themes/` folder.
- In VS Code, run **Developer: Generate Color Theme From Current Settings** to export the theme you use
  right now.

Custom themes can be renamed, edited and deleted in the same list. Deleting shows an **Undo** button.

## Fonts

Under **Fonts** you choose one font for **Text and interface** and one for **Code**. Each comes with a
sample line.

- **Text and interface**: Inter (default), the system font, Geist, IBM Plex Sans, Source Sans 3, Open
  Sans, Roboto, Noto Sans, Figtree or Atkinson Hyperlegible Next.
- **Code**: the system font (default), JetBrains Mono, Fira Code, Geist Mono, Source Code Pro, Cascadia
  Code or Roboto Mono.

These fonts are served by your own Selfbound instance, not by an outside font service, and a font is only
downloaded once you select it. To use a font installed on your computer, choose **Installed locally …**
and type its name, for example `Berkeley Mono`. A local font only shows on devices that have it
installed.

## Font size

**Font size** offers **Small**, **Normal** and **Large** for this device. Row heights in lists stay the
same, so lists stay fast with thousands of issues.

## Sounds

Selfbound plays soft sounds for clicks, keys, menus, success and errors. Turn them off or change the volume
under **Settings → General → Sounds**. This applies to the current device; dragging the volume slider
plays a sample click.

## Reduced motion

If your system asks for reduced motion, Selfbound keeps only short fades and leaves out sliding and springy
animations. There is no separate setting in Selfbound for this; it follows the system.

<Aside type="tip">
Settings → General also has **Teams in the sidebar**: **Small** shows logo and name, **Large** adds the
counts for every team.
</Aside>
