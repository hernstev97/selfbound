Selfbound cannot import GitHub issues yet. Today the only importer is the one for [Linear](/integrations/import-linear/). The [GitHub integration](/integrations/github/) links pull requests to Selfbound issues, but it does not copy issues from GitHub.

<Planned issue="XLR8-48" title="GitHub Issues importer">
An importer for GitHub Issues is planned. The idea:

- Import one or more repositories into a Selfbound team.
- Bring over title, description, open or closed state, labels, comments and dates, plus references to pull requests.
- Run it again later without creating duplicates.
</Planned>

Until then, you can move a small number of issues by hand, or let an AI agent read them from GitHub and create them in Selfbound.
